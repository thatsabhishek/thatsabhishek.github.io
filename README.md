# Abhishek Gupta Portfolio — redesign

A responsive, static portfolio with an editorial/creative visual direction (warm off-white, ink black, chartreuse accent, oversized typography, geometric artwork).

## Preview locally

No build step or package install is needed. Open `index.html` in a browser, or run a simple local server:


```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy to GitHub Pages

1. Extract the folder contents into your GitHub Pages repository.
2. Commit and push to the branch configured for Pages.
3. Keep `index.html` at the repository root.


## Included pages

- `index.html` — main portfolio
- `projects.html` — project index
- `projects/` — individual project detail pages
- `certificates.html` — certificate archive
- `badge.html` — legacy route redirecting to the archive
